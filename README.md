## 📦 Core Features (Layanan Utama)

Sistem ini membagi fungsionalitasnya untuk memberikan pengalaman pengguna (UX) yang mulus bagi pelanggan, sekaligus memberikan kontrol manajerial yang kuat bagi mitra penyedia ruang.

| 🚀 Fitur Unggulan | Deskripsi Sistem |
| :--- | :--- |
| **Smart Storage Management** | Pencatatan inventaris penitipan barang secara otomatis dengan perhitungan tarif dinamis berdasarkan durasi waktu dan dimensi barang. |
| **Real-Time Order Tracking** | Pemantauan status barang dan pelacakan transaksi secara langsung melalui integrasi REST API yang responsif. |
| **Partner & Vendor Dashboard** | Modul khusus bagi mitra logistik/penitipan untuk mengelola pesanan masuk, memverifikasi barang, dan melihat rekapitulasi pendapatan. |
| **Seamless User Experience** | Antarmuka interaktif yang dirancang khusus untuk kenyamanan transaksi via perangkat seluler (<i>Mobile-First UI</i>). |

## 🏗️ Teknologi & Infrastruktur

Aplikasi ini mengandalkan arsitektur *Full-Stack* dengan pemisahan lalu lintas data melalui REST API yang cepat, efisien, dan siap diskalakan.

<div align="center">
  <br/>
  <a href="https://skillicons.dev">
    <img src="https://skillicons.dev/icons?i=js,tailwind,html,css,mysql,php,laravel,git&perline=8&theme=dark" alt="TitipSini Tech Stack" />
  </a>
  <br/><br/>
</div>

*   **Frontend Engineering:** Pemanfaatan **JavaScript (ES6)** dan **Tailwind CSS** untuk menyajikan komponen antarmuka yang reaktif, bersih, dan modern tanpa waktu *loading* yang lama.
*   **Backend & API:** Sistem pengolahan data terpusat (*RESTful API*) yang melayani *request* data dari aplikasi pelanggan maupun *dashboard* mitra secara instan.
*   **Database Schema:** Skema basis data relasional (*MySQL*) yang dioptimalkan untuk menampung riwayat transaksi penitipan dalam volume besar.

## 🚀 Panduan Instalasi (Quick Start)

Untuk menjalankan proyek ini di *localhost* Anda:

```bash
# 1. Clone repositori aplikasi
git clone [https://github.com/UlulAzmiALatala/TitipSini-App.git](https://github.com/UlulAzmiALatala/TitipSini-App.git)
cd TitipSini-App

# 2. Install semua dependensi
npm install
composer install # (Jika dihubungkan dengan backend Laravel/PHP)

# 3. Sesuaikan file environment
cp .env.example .env

# 4. Inisialisasi Database
php artisan migrate

# 5. Jalankan server lokal
npm run dev
```
